# Jiawei Gao Academic Homepage

This is a GitHub Pages academic homepage migrated from the Google Sites homepage at:

https://sites.google.com/view/jiaweigao/home

## Files

- `index.html` contains the full homepage content and section structure.
- `styles.css` contains the visual design.

## Deploy With GitHub Pages

1. Create a GitHub repository, for example `gaojiawei321.github.io`.
2. Upload `index.html`, `styles.css`, and any future `assets/` files to the repository root.
3. In GitHub, open `Settings` > `Pages`.
4. Select `Deploy from a branch`.
5. Choose the `main` branch and root folder `/`.
6. Wait for GitHub Pages to publish the site.

The site will be available at:

https://gaojiawei321.github.io/
